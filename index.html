常见解答与疑问

BiliNote 采用开放协议架构。你可以无缝连接任何提供 OpenAI 兼容接口的大模型供应商（例如商汤日日新、DeepSeek、阿里通义千问、Groq、SiliconFlow 或本地 Ollama / vLLM）。在软件设置面板中填入你的专属 Base URL 与 API Key 即可。

我们没有自己的中转服务器。所有多媒体下载、截帧、本地 Whisper 转写和生成的笔记都纯粹存储在你本机的 backend/data/ 目录下。仅当你主动配置了云端大模型 API 时，音频提取出的文字转录稿会被发送到你指定的模型服务商用于生成摘要。

部分流媒体平台具有较严格的匿名反爬策略。B 站的大多数公开视频已实现免登录指纹自动生成；对于视频号和抖音，BiliNote 设置页面提供了非常清晰的一键 F12 抓取指引，填入一次即可稳定调用数月，Cookie 纯本地加密保存。
